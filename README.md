# SegurAPP - Frontend 

## Instalación

1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar las dependencias.

## Librerías instaladas

* **expo-location**: Para el rastreo de GPS en tiempo real.
* **react-navigation**: Para la lógica de pestañas y pantallas.
* **expo-vector-icons**: Para la iconografía de la app.

## Pruebas en Dispositivos

* **Herramienta**: Expo Go

* **Plataforma**: Celular Android
